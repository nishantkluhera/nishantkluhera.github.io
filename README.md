# Nishant Luhera - Modern Portfolio Website

A modern, responsive portfolio website showcasing my projects, skills, and professional journey.

🌐 **Live Site**: [https://nishantkluhera.github.io/](https://nishantkluhera.github.io/)

## ✨ Features

- **Modern Design**: Clean, contemporary UI with beautiful gradients and animations
- **Responsive Layout**: Optimized for all devices and screen sizes
- **Dark/Light Theme**: Toggle between themes with persistent preference
- **Smooth Animations**: Engaging scroll-triggered animations and transitions
- **Dynamic Content**: Real-time data from GitHub and LeetCode APIs
- **Interactive Navigation**: Smooth scrolling navigation with visual feedback
- **Performance Optimized**: Fast loading with efficient CSS and JavaScript

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3 (Modern CSS Grid & Flexbox), Vanilla JavaScript
- **Fonts**: Inter & JetBrains Mono from Google Fonts
- **Icons**: Font Awesome 6
- **APIs**: GitHub API, LeetCode Stats API
- **Deployment**: GitHub Pages

## 📱 Sections

1. **Hero Section**: Dynamic profile with animated avatar and statistics
2. **About**: Skills and expertise showcase with animated cards
3. **Projects**: Personal and collaborative repositories from GitHub
4. **Statistics**: GitHub activity and LeetCode progress metrics
5. **Contact**: Social media links and contact information

## 🎨 Design Features

- **Color Palette**: Modern indigo-based color scheme with gradients
- **Typography**: Clean Inter font family with proper hierarchy
- **Animations**: Floating avatar, fade-in cards, and hover effects
- **Accessibility**: Proper ARIA labels and keyboard navigation
- **Cross-browser**: Compatible with all modern browsers

## 🚀 Performance

- Optimized CSS with CSS custom properties (variables)
- Efficient JavaScript with error handling
- Responsive images and lazy loading
- Minimal external dependencies
